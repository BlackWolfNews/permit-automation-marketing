# Permit Automation Suite public funnel

This repository is the public marketing funnel for Permit Automation Suite. It is separate from the application repositories `permit-automation-suite`, `permit-estimator`, and `carrier-vehicle-lookup`.

The lite pages are not built yet. Planned pages:

- Permit structures / routing rules
- Night travel
- Escorts and pilot cars
- Holiday restrictions

## Live tools

Two tools are already live on their own:

- [Carrier Vehicle Lookup](https://web-tau-blush-50.vercel.app/)
- [Estimator](https://permit-automation-estimator.vercel.app/estimate)

[Permit Automation Suite](https://permit-automation-suite.vercel.app/) is the place to store a truck and trailer and use every tool for one price.
